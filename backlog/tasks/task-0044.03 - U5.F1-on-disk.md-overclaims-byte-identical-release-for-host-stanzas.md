Source: UAT log entry `U5` in `go-hasp.support/UAT.md`. That file lives outside this repository (a sibling directory) and is not tracked here; it is quoted below as it stood on 2026-11-25. Findings there are append-only.

Severity: major. v1.0.0 blocker judgment in the log: Recommend yes.

Finding text, verbatim:

> `on-disk.md`'s withdrawal path claims release carries *"the same byte-identical guarantee M2's own exit criteria hold `adopt`/`release` to"*. For **host stanzas** that is false: M2's criterion is key-scoped and its section explicitly defers hosts to M3, and M3 requires only that a stanza return to plain text *"with its content intact"*. Keys and profiles do come back byte-identical, so hosts are the single overclaimed noun. The binary is correct; the trust document overstates it, to the one reader least equipped to notice. Recommended for v1 because it is a text-only fix with no code risk, and because this is the document a user reads to decide whether trialling is safe at all.
