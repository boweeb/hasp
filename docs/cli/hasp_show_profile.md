## hasp show profile

Show a profile's keys and hosts, aggregated across child profiles by default

```
hasp show profile <name> [flags]
```

### Options

```
  -h, --help         help for profile
      --no-recurse   scope to the named profile alone, without descendants
```

### Options inherited from parent commands

```
      --json             machine-readable output
      --key-dir string   key directory (default ~/.ssh) (default "~/.ssh")
      --no-color         disable ANSI color in human output
      --verbose          enable diagnostic logging to stderr
      --yes              consent to apply a write non-interactively
```
